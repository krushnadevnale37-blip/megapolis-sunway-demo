MEGAPOLIS SUNWAY - LOCAL DEFAULTER REPORT WEBSITE

FIRST-TIME SETUP
1. Extract the ZIP file into a folder on your computer.
2. Make sure Python is installed.
3. Double-click START_WEBSITE.bat.
4. Wait while the required packages install.
5. Your browser should open at http://127.0.0.1:5000.
   If it does not, copy that address into Chrome.

HOW TO USE
1. Select the Defaulter Excel file (.xlsx or .xlsm).
2. Select the Society Word template (.docx).
3. Click Proceed – Generate Report.
4. The generated Word report will download automatically.

IMPORTANT
- Keep the black Command Prompt window open while using the website.
- To stop the website, close that black window or press Ctrl+C.
- This website runs only on your computer. Files are processed locally.
- Expected Excel columns: Block, Unit #, Overdue Days, Pending Amount.
- A01 and A02 block subtotal rows are omitted, as previously requested.
- The Word template header/footer is retained; its main body is replaced by the generated report.
- Check the generated report carefully and obtain committee approval before circulating member dues information.
